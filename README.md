## Overview

**E-faktura** is a commercial application focused on electronic invoicing and business workflows. The project was created to support the preparation, management and processing of invoices in a structured digital environment.

This repository is a public showcase. It contains documentation and information about the project, but not the original source code.

---

## Project type

**Commercial business application — source code private**

The source code is private because of commercial agreements and intellectual property considerations.

---

## Main areas

The project is related to:

- electronic invoice workflows,
- structured business documents,
- invoice management,
- business process support,
- data validation,
- integration with other business operations.

Specific implementation details are intentionally limited because the system is part of private commercial work.
